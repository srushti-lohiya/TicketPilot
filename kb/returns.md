# Returns
## Starting a return
Go to Orders, pick the order, and choose Return items. Print the prepaid label. Returns are free within the US for orders over $50; otherwise a $6.95 return shipping fee is deducted from the refund.
## Exchanges
We do not do direct exchanges. Return the item for a refund and place a new order. For size swaps, we can reserve the new size for 7 days.
